# Glossário da reunião

> Modelo. O HELIOS cria `Documentos\HELIOS\glossario.md` a partir deste arquivo se ele não existir.
> Uma linha por termo, no formato `termo = como traduzir ou o que significa`. Só entram na tradução os termos que aparecem na fala.
> Não coloque senhas, chaves ou e-mails aqui: linhas assim são ignoradas.

- sprint = sprint (ciclo curto de trabalho; não traduzir)
- standup = reunião diária rápida do time
- PR = pull request (pedido de revisão de código)
- checkout = finalização da compra (e-commerce)
- storefront = vitrine da loja virtual
- deploy = publicação / colocar no ar
