# Glossário da reunião

> Modelo. O HELIOS cria `Documentos\HELIOS\glossario.md` a partir deste arquivo se ele não existir.
> Uma linha por termo, no formato `termo = como traduzir ou o que significa`. Os termos entram no Whisper e na tradução.
> Não coloque senhas, chaves ou e-mails aqui: linhas assim são ignoradas.

- Wake = plataforma de e-commerce Wake Commerce
- Storefront SSR = renderização server-side da vitrine
- Scriban = linguagem de templates da vitrine
- Nuvemshop = plataforma de e-commerce Nuvemshop
- VTEX = plataforma de e-commerce VTEX
- Fbits = plataforma Fbits / Wake
- ClickUp = gestão de tarefas e projetos
- Ronda = plataforma SaaS Ronda
- Prancheta = plataforma SaaS Prancheta
- OpenBot = assistente desktop local
- Next.js = framework React
- Supabase = banco PostgreSQL e autenticação
- PDP = página de detalhe do produto
- PLP = página de listagem de produtos
- checkout = finalização da compra
- storefront = vitrine da loja virtual
- sprint = sprint (ciclo curto de entregas)
- PR = pull request (revisão de código)
- deploy = publicação em produção
